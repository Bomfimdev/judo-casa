# Judo Casa

App **web + iOS/Android** do projeto social de judô no **Instituto Casa Oficial** (Casa de Adoração Profética — Samambaia / Brasília).

> Produto **separado** do [ICHTHUS Judô](https://github.com/Bomfimdev/ICHTHUS-JUDO). Sem mensalidade. Campeonato: inscrição e marcação **sem pagamento** no MVP.

## Status

Épico de produto **travado** (2026-10-29). Próximo: plano técnico + UI.
