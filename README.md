# Judo Casa

App **web + iOS/Android** do projeto social de judô no **Instituto Casa Oficial** (Casa de Adoração Profética — Samambaia / Brasília).

> Produto **separado** do [ICHTHUS Judô](https://github.com/Bomfimdev/ICHTHUS-JUDO). Sem mensalidade. Campeonato: inscrição e marcação **sem pagamento** no MVP.

## Status

Épico + stack + **UI/UX** travados (2026-10-29). Scaffold Expo com home no estilo do protótipo.

**Stack:** Expo + Supabase · **UI:** [`docs/design/judo-casa-ui-prototype.html`](docs/design/judo-casa-ui-prototype.html)

## Rodar (~1 min)

```bash
cd D:\projetos\judo-casa
npm start
```

Depois: `w` (web) ou Expo Go no celular.
